# Student Management Console Application

## Purpose
The **Student Management Console Application** is a modular Java console application designed to store, retrieve, update, and manage student records. Built using Object-Oriented Principles (OOP), exception handling, and file persistence via CSV storage.

---

## Features
1. **Register Students**: Add new student profiles containing ID, Name, Email, Department, and Level.
2. **View All Students**: Display a clean, formatted list of all registered student records.
3. **Search Students**: Search and view detailed information for any student by ID.
4. **Edit Information**: Update student profile attributes (Name, Email, Department, Level).
5. **Delete Information**: Permanently remove student profiles from the system.
6. **Save Records**: Persist in-memory records directly to `resources/students.csv`.
7. **Load Records**: Load and parse persistent student data from disk.

---

## Technologies Used
- **Language**: Java (JDK 17 or higher)
- **Data Persistence**: CSV (Comma-Separated Values)
- **Development Tools**: VS Code
